# HiFiTi 一键存网盘

当前版本：**1.0.0**，以当前代码作为项目第一版。

在 HiFiTi（音乐磁场）页面读取音乐分享，使用浏览器已有登录态，将资源保存到夸克网盘。适用于 Windows Edge 与 Tampermonkey，采用 MIT 许可证。

## 功能

- 点击保存按钮后，按需通过网站原表单回帖解锁，读取分享链接与提取码，打开夸克并转存。
- 默认直接保存到夸克根目录下的 `/HiFiTi音乐/`，可修改目标文件夹，保留分享原有目录结构。
- 同名文件按名称和大小核对；同名文件夹递归核对名称、类型、大小和数量。匹配则跳过，不一致则暂停，不覆盖已有文件。
- 每天访问 HiFiTi 时自动签到，可关闭或手动检查；显示金币余额，点击余额可刷新。
- 百度网盘提供带提取码的分享入口，转存需手动完成。
- 资源保存、每日签到、偏好设置三个页签，支持收起面板和键盘切换页签。

## 安装与使用

1. 在 Edge 安装 Tampermonkey 等用户脚本管理器，并按管理器提示允许运行用户脚本。
2. 打开[正式脚本](https://raw.githubusercontent.com/nayunfeng/hifiti-save/main/dist/hifiti-save.user.js)，按管理器提示安装。也可以新建用户脚本，用 `dist/hifiti-save.user.js` 全文替换默认内容并保存。
3. 在同一浏览器配置中登录 HiFiTi 和 [夸克网页版](https://pan.quark.cn/)。若同时使用其他自动回帖脚本，请先关闭其自动回帖功能。
4. 打开歌曲帖子，在右下角「HiFiTi 助手」的「偏好设置」中确认保存目录与评论内容。
5. 在「资源保存」选择夸克分享，再点击保存。首次回复隐藏帖时会发表设置中的评论，默认「感谢分享。」，按站方规则预计扣 1 金币。仅浏览帖子或选择资源不会发表评论。
6. 保持原帖和夸克标签页开启，直到显示确认结果。遇到登录、真人验证或提取码缺失时，手动处理后点击继续。

脚本执行网盘转存，不会把音频下载到电脑。

## 范围与限制

- 自动签到只在访问网站时运行，按北京时间和账号记录每日状态，关闭浏览器后不会后台签到。
- 只识别夸克和百度的 HTTPS 分享链接，不读取评论区、脚本或显式隐藏节点中的资源；不能可靠匹配提取码时不猜测。
- 不绕过 VIP、付费或其他访问限制。必要时先在官网手动展开内容，再点击「重新读取资源」。
- 一次处理一个分享；顶层超过 100 项时暂停。同名目录核对上限为深度 8、文件夹 20、累计列表项目 400。
- 名称和大小相同不等于文件内容哈希相同。
- 评论或转存结果不明确时不会自动重复提交。已有任务编号时查询原任务，否则请先到官网或网盘核对。
- 任务接力有效期为 30 分钟。过期后重新发起前，请先核对之前是否完成。
- 官网结构、夸克网页接口和浏览器策略变化可能需要适配；其他浏览器或脚本管理器未保证兼容。

## 数据与权限

脚本匹配 HiFiTi 页面和夸克分享页，网盘跨域请求仅允许 `drive-pc.quark.cn`。签到直接访问 HiFiTi 本站，评论使用当前页原表单。请求沿用当前账号，不读取或导出登录 Cookie、密码。

设置、签到状态和任务记录保存在脚本管理器的本机存储中，包括目录、评论、账号名称、帖子与分享编号、提取码及任务状态。没有广告、统计上报或额外后端。删除脚本及其存储可清除这些记录。

## 开发与验证

建议使用 Node.js 22。

```powershell
npm ci --ignore-scripts
npm test
npm run build
node --check dist/hifiti-save.user.js
npm run preview
```

本地演示地址：`http://127.0.0.1:8927/thread-42.htm`。演示使用模拟解锁与夸克接口，不会发送真实评论或写入真实网盘。安装页可通过 `node install.cjs` 启动，地址为 `http://127.0.0.1:8928/`。

测试覆盖资源与提取码匹配、隐藏内容过滤、分页、防重复提交、任务恢复、同名文件核对、签到和余额读取。测试与本地演示不能替代真实网站兼容性验证。
